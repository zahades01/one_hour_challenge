# Frontend Development

## Key Files
- `ui/src/components/` - React components
- `ui/src/components/ui/` - shadcn components
- `ui/src/lib/utils.ts` - Utility functions

## Patterns
- Use shadcn MCP to search and install components
- Tailwind for styling
- React hooks for state

## For Complex Tasks
Use `mcp__playwright__*` for visual testing.
